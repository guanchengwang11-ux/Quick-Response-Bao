# Quick Response Bao 1.0.0-rc.3 人工兼容性测试

## 使用说明

每个应用都必须逐项执行 1–30。状态只能填写 `Pass`、`Fail` 或 `Not Tested`。失败时必须填写实际结果、复现步骤、截图位置和错误日志位置。诊断报告不得包含完整键盘输入、聊天内容、密码、验证码或完整剪贴板内容。

测试数据至少准备：英文触发词、中文正文、英文正文、多行正文和长话术。分别在浅色/深色、125%/150%/175%、主显示器/第二显示器测试。

## 统一步骤定义

1. 启动 Quick Response Bao。
2. 在诊断页确认目标程序命中白名单。
3. 打开普通聊天或文本输入框。
4. 输入少于 4 个连续检索字符（英文字母或非开头空格）。
5. 确认候选框不出现。
6. 输入第 4 个连续检索字符；至少额外验证 `how `（结尾为空格）和 `solve this`。
7. 确认候选框出现。
8. 检查摘要显示在正文上方。
9. 检查摘要和正文完整。
10. 检查匹配文字为清晰的红色高亮。
11. 继续输入并确认结果实时刷新。
12. Backspace 删除并确认结果刷新。
13. 上下方向键切换候选。
14. Enter 选择话术。
15. Tab 选择话术。
16. Esc 关闭候选框。
17. 检查鼠标悬停和点击。
18. 用鼠标滚轮查看长话术。
19. 确认候选框不抢走输入焦点。
20. 确认自动粘贴完整。
21. 检查中文、英文和多行内容。
22. 确认不会自动发送消息。
23. 确认原剪贴板恢复；同时检查诊断页状态。
24. 切换窗口并确认候选框隐藏。
25. 检查浅色主题。
26. 检查深色主题。
27. 检查 125%、150%、175% 显示缩放。
28. 检查主显示器和第二显示器。
29. 记录定位方式：Caret / 当前窗口右下角 / 当前显示器右下角。
30. 记录所有失败现象、最小复现步骤和非敏感诊断报告。

## 失败诊断顺序

1. 在诊断页核对前台进程、白名单、Hook、文本输入环境和缓冲长度。
2. 核对候选框定位方式；Caret 失败应降级到当前窗口右下角，再降级到当前显示器右下角，而不是完全隐藏。
3. 核对最近粘贴状态、剪贴板恢复状态、最近错误和日志目录。
4. 导出安全诊断报告并附在失败记录中。报告只包含窗口标题长度，不包含窗口标题内容、输入缓冲内容或剪贴板内容。
