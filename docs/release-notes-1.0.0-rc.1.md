# Quick Response Bao 1.0.0-rc.1

Internal Release Candidate for installation, portable-package, update, theme and compatibility validation. It is not the final v1.0.0 release.

- Release / win-x64 / self-contained build.
- Includes the independent updater, Excel import/export, category and batch management, database backup/restore, themes and safe diagnostics.
- User data remains under `%LocalAppData%\QuickResponseBao` and is not included in program packages.
- SHA-256 verification is mandatory for update installation.

Known release gate: complete the manual Lark, Telegram, Discord, Chrome and Edge matrix before promoting to v1.0.0.
