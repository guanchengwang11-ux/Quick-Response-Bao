# V1.0.0 测试记录

自动测试命令：`dotnet test QuickResponseBao.sln --configuration Release`。

Tag 发布前还必须在 Windows 10 x64 和 Windows 11 x64 上，分别对 Lark、Telegram、Discord、Chrome 和 Edge 执行候选显示、焦点保持、键鼠选择、Unicode/多行粘贴、剪贴板恢复及“不自动发送”检查。

## 兼容性诊断流程

1. 在“诊断”页确认目标进程名、窗口标题、白名单、Hook 和文本输入环境状态。
2. 在目标输入框中运行“测试候选悬浮窗口”，记录 Caret、当前窗口右下角或屏幕右下角定位方式。
3. 运行“测试剪贴板粘贴”，确认只粘贴固定测试短语、不模拟 Enter，并检查最近一次结果。
4. 分别验证普通文本、多行 Unicode、鼠标选择和键盘选择；不得在密码或验证码输入框测试。
5. 失败时导出安全诊断报告并记录应用版本；报告只包含缓冲区长度和窗口标题长度，不包含实际输入、聊天内容或剪贴板内容。
