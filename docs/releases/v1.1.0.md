# Quick Response Bao v1.1.0

## Major UI & UX Upgrade

Quick Response Bao v1.1.0 delivers a completely redesigned Fluent interface and a faster, clearer desktop experience for daily customer-support work.

## What's New

- Completely redesigned Fluent interface
- New modern navigation and page structure
- Faster response library with smoother large-list performance
- Excel-style multi-column filtering
- Improved candidate suggestion window
- Better import and export workflow
- Modern settings and privacy-safe diagnostics
- Light, Dark, and System theme support
- Better DPI scaling, keyboard focus, and accessibility support
- Single-instance protection to prevent duplicate candidate windows
- Improved application responsiveness

## Response Library

- Search Summary, Content, Keywords, and Category
- Filter individual columns and combine multiple filters
- Clear active filters quickly with visible filter status
- Improved mouse-wheel and keyboard scrolling
- Faster operation with large response libraries
- Batch enable, disable, delete, and category movement
- Modern response editor with bilingual length feedback

## Candidate Suggestions

- Cleaner layout and clearer matching highlights
- Improved scrolling and keyboard navigation
- Enter, Tab, and mouse confirmation remain supported
- Typed search text is safely replaced without duplicate content
- Duplicate application instances and candidate windows are prevented

## Performance

- Faster page navigation
- Reduced database reloads
- Virtualized large response libraries
- More responsive search and filtering

## Compatibility

- Windows 10 x64
- Windows 11 x64
- Lark, Telegram, Discord, Chrome, and Edge input workflows

## Important

Upgrading does not delete existing responses, categories, keywords, settings, application whitelist entries, backups, usage counts, or last-used information. User data remains under the existing LocalAppData location and is not stored in the installation directory.

## Known limitations

- If the target application runs as Administrator, Quick Response Bao may also need to run with the same permission level for global input and paste operations.
- Candidate positioning depends on the accessibility information exposed by the target application. When caret positioning is unavailable, Quick Response Bao automatically uses its window or monitor fallback position.
